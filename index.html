PHANTOM RECALL: Distinguishing and Mitigating Memorization in Large Language Models

Lead Student Researcher | Expected Completion: Dec 31, 2026

This project investigates the distinction between genuine reasoning and memorized recall in Large Language Models (LLMs) through systematic benchmark variations that preserve logical structure while altering surface-level representations.

  • Phase I (Completed): Constructed benchmark variations and developed an automated error-classification system successfully achieving 96% agreement with human annotators.
  • Phase II (In Progress): Developing prompting-based interventions designed to reduce reliance on memorized patterns and improve reasoning robustness.
  • Expected Deliverables: An open-source benchmark suite, an automated reasoning-failure taxonomy, public software release, and a peer-reviewed publication by December 31, 2026.
  • Research Team: R. Baral (Lead), N. Mahajan, Prof. C. Baral, Prof. V. Gupta.

Unified 2D/3D Multi-Task Framework for Clinical Radiographs

Clinical Data Pipeline & Diagnostic Architectures

Engineered a dimension-agnostic deep learning framework using PyTorch and Axial-Coronal-Sagittal (ACS) convolutions to unify 2D and 3D medical image analysis across 18 MedMNIST v2 datasets.

  • Semi-Supervised Pipeline: Developed a Student-Teacher pipeline integrating RAD-DINO and Exponential Moving Averages (EMA) to leverage 184,556 unlabeled MIMIC-CXR images, achieving a state-of-the-art Test AUC of 0.878.
  • Ark Cyclic Training: Implemented within a ResNet-50 backbone to eliminate gradient interference across concurrent classification, localization, and segmentation tasks.
  • Optimization: Optimized deployment on Apple M3 silicon to achieve a 2.4x throughput increase.
  • Clinical Pipeline: Built a medical imaging pipeline using pydicom to parse metadata and normalize high-bit-depth DICOM scans, and designed a hybrid U-Net architecture achieving 98.42% validation pixel accuracy.
